AI-Powered Resume Screening and Recruitment System
A comprehensive enterprise-grade recruitment platform leveraging Natural Language Processing and Machine Learning to automate resume screening, candidate ranking, and skill gap analysis.



OVERVIEW



The AI-Based Resume Screening and Recruitment System is a full-stack web application designed to streamline the recruitment process. It automates the tedious task of manual resume screening by using advanced NLP techniques to parse resumes, extract relevant information, and rank candidates based on their alignment with job descriptions.

The system provides actionable insights including skill gap analysis, bias detection, and explainable AI recommendations, making it a comprehensive solution for modern recruitment needs.

Built as a collaborative college project by a team of 4 developers over 4 weeks.

Key Features



Core Functionality

Bulk Resume Processing: Upload multiple resumes in PDF or DOCX format simultaneously

Intelligent Resume Parsing: Automated extraction of name, email, phone, skills, education, and work experience

Smart Candidate Ranking: Multi-modal scoring combining keyword matching, semantic understanding, and skill overlap

Interactive Dashboard: Visual representation of rankings, skill distributions, and match analytics



Advanced Capabilities



Skill Gap Analysis: Identifies missing skills and provides actionable recommendations for each candidate

Explainable AI: Displays keywords and factors contributing to match scores using LIME/SHAP techniques

Bias Detection: Compares rankings with anonymized resumes to detect potential demographic biases

Real-Time Progress: WebSocket-based live updates during resume processing

Automated Communication: One-click shortlisting with automated interview invitation emails





User Roles
HR / Recruiter: Post jobs, upload resumes, view rankings, shortlist candidates

Candidate: Upload resume, track application status, view skill recommendations

Administrator: Manage users, monitor system health, view analytics
